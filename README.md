## 🔥 Algorithms & Patterns

This project focuses on mastering key problem-solving patterns:

- DFS / BFS
- Recursion
- Backtracking
- Dynamic Programming (memoization & tabulation)
- Sliding Window
- Graph traversal & cycle detection

## 📊 Complexity Overview

| Topic | Time Complexity | Space Complexity |
|------|---------------|----------------|
| DFS / BFS | $O(V + E)$ | $O(V)$ |
| Tree Traversals | $O(n)$ | $O(h)$ |
| Dynamic Programming | $O(n)$ | $O(n) / O(1)$ |
| Backtracking | $O(2^n) / O(n!)$ | $O(n)$ |
| Sliding Window | $O(n)$ | $O(k)$ |
