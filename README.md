## 🧠 Topics Covered

### 🌳 Trees
- Binary Tree Traversals (DFS, BFS)
- Tree height / depth
- Tree problems (sum, search, path sum, invert, etc.)

### 🧠 Dynamic Programming
- Fibonacci (multiple approaches)
- Climbing Stairs
- House Robber

### 🧱 Stack & Queue
- Stack implementation
- Valid Parentheses
- Min Stack
- Queue (deque)
- Moving Average (sliding window)

### 🔁 Backtracking
- Generate Parentheses
- Subsets
- Permutations
- Combination Sum

### 🌐 Graphs
- DFS (Depth-First Search)
- BFS (Breadth-First Search)
- Number of Islands (grid DFS)
- Course Schedule (cycle detection / topological sort)

## 🔥 Algorithms & Patterns

This project focuses on mastering key problem-solving patterns:

- DFS / BFS
- Recursion
- Backtracking
- Dynamic Programming (memoization & tabulation)
- Sliding Window
- Graph traversal & cycle detection

## 📊 Complexity Overview

| Topic | Time Complexity | Space Complexity |
|------|---------------|----------------|
| DFS / BFS | O(V + E) | O(V) |
| Tree Traversals | O(n) | O(h) |
| Dynamic Programming | O(n) | O(n) / O(1) |
| Backtracking | O(2^n) / O(n!) | O(n) |
| Sliding Window | O(n) | O(k) |

This project is meant to:

- Prepare for **technical interviews**
- Practice **problem-solving patterns**
- Serve as a personal **learning reference**
